NOTE TO KNOWLEDGE TREE

筆記生長樹

把零散筆記變成一棵可以看見脈絡、枝幹與關係的知識樹。

這是依據你提供的 Threads 截圖方向整理出的獨立頁面：重點不是單純搜尋，而是讓筆記自動長成一張地圖。你可以直接貼 Markdown、條列筆記或主題整理，頁面會在瀏覽器本地端解析並生成樹狀視覺圖。

開始生成知識樹Threads 來源

找到的開源方向：NoteGraph

我找到最接近你截圖描述的開源方向，是 Joplin 的 NoteGraph 外掛。它的定位是把目前選取的筆記轉成互動式 AI 知識圖，會抽取概念、實體、事件與彼此關係，並支援 Tree、Radial、Force、Circle、Grid 等布局。

GitHub 專案Joplin Forum

這頁做成什麼

  • 先做成可直接使用的「筆記轉樹」網頁原型。
  • 目前不需要登入、不需要 API key，資料只在瀏覽器中處理。
  • 適合之後接到星火計畫：學習筆記、課程脈絡、數學能力樹、作文架構、專題研究。
